# MLBB TacticalPick — Télécharger l’app

Assistant de draft pour Mobile Legends: Bang Bang sur Android.

[**Télécharger l’APK signé — version 0.1.0**](https://github.com/Harinony/MLBB-TacticalPick-APK/raw/refs/heads/main/releases/TacticalPick-0.1.0-release.apk)

Android **8.0 ou plus récent**, environ **9 Mo**.
[Empreinte SHA-256](releases/TacticalPick-0.1.0-release.apk.sha256).

## Installation

1. Téléchargez l’APK sur votre téléphone Android.
2. Ouvrez le fichier et autorisez l’installation depuis le navigateur si Android le demande.
3. Dans l’onglet **Assistant**, autorisez la superposition et activez la bulle pour utiliser le panneau au-dessus du jeu.

La version 0.1.0 est un premier prototype : la compatibilité avec MLBB dépend de l’appareil.
Une ancienne version debug doit être désinstallée avant cette version signée,
ce qui efface ses données locales. Les prochaines mises à jour de distribution
conserveront la même clé de signature.

Ce dépôt contient les APK de distribution et les instructions d’installation.
Le code du projet et les clés de signature ne sont pas publiés ici.
